1. `CS_NPC_OPEN (0x0016)` 打开 NPC。
2. 收到 `SC_NPC_DIALOG (0x001D)` 并确认目标功能 ID。
3. `CS_NPC_FUNCTION (0x0017)` 选择功能。
4. 收到包含相同功能 ID 的 `SC_QUEST_DETAIL (0x001E)`。
5. `CS_QUEST_ACTION (0x0018)` 确认；功能字符串后的 `u16` 为 `0` 表示接取、`1` 表示交付，之后是固定 `u32 0` 和实时 `u32 sequence`。

## 停止与恢复

“登山爬塔”与自动除暴、自动捐献、自动跑环共享自动化独占锁。关闭 ACTIVE、手动停止、连接/发包失败、地图不符、服务端拒绝传送、背包空间不足或阶段超时都会停止后续发包。程序不会自动丢弃背包物品。

同一客户端运行期间会根据 `0x0027/0x003E/0x003F` 维护三项任务的进行和完成状态；停止后再次启动会跳过已经完成的路线。应用重启后只使用本次登录服务端明确下发的活动任务状态，不把旧会话结果当作当前角色状态。
